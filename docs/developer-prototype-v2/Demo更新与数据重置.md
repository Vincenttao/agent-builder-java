# Demo 更新与数据重置

日期：2026-10-25。用户要求：删除旧 Demo 历史数据，今后每次更改 Demo 都清理，避免旧状态误导评审。

## 规则与实现

- 构建时对 `src/index.html`、`src/style.css` 和 `src/app.js` 的内容计算 SHA-256，写入页面的 `demo-build` 标记。相同内容重复构建保持标记；任一文件变化产生新标记。单文件 Demo 和 HTTP 源码预览使用同一版本算法。
- 首次加载新版或发现旧数据包时，清理 `openjiuwen-workbench-v2-demo-数字` 这些本 Demo 的存储键。重新初始化全部应用、草稿、对话、Mock 业务、运行、候选、交接及平台演示状态；不迁入旧数据。
- 同版刷新、身份/应用切换仍保存当前进度。保存的数据携带内容版本，旧标签页发现存储已切到新版后不再写回，并提示刷新。
- 只清理当前浏览器、当前入口下本 Demo 的存储，不使用 `localStorage.clear()`，不清理其他应用或仓库历史证据。用户刷新新版后触发清理；不能据本地自动化浏览器测试宣称已远程修改用户另一个浏览器。
- 无有效版本的源码 HTML 直开不保留旧数据；使用构建后的单文件或本机服务作为正式 Demo 入口。

这是一阶段演示数据策略。真实产品的版本、审计、候选与运行持久化要求保持原设计。
