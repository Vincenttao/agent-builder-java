# Agent Builder 文档

Agent Builder 面向企业 AI 平台开发者与应用开发者。当前产品方向以 [PRD 2.0](Agent开发工作台_PRD_v2.0.md) 为准：平台方发布范式和模板，应用方配置、装配与少量开发，双方共同联调，形成可交给企业 CI/CD 的应用。以 MOA 开发模板创建 i豆场景应用贯穿设计，以注入范式开发 Skill 的 OpenCode 为核心编排助手，两类用户使用不同工作区且均可查看和简单修改代码。

本次交付 PRD、交互设计和双角色可点击 Demo。Demo 使用本地模拟；第二、三阶段先讨论技术方案，再开发前后端。现有设备/工单等路径、工程生成和 RP-01 Demo 保留原验证记录；MOA/i豆接入及独立服务交付尚待实施。当前可信本地运行方式不等于 MOA Native Skill 所需的 Runtime Sandbox 已接通。

首次体验请看[仓库 README](../README.md)；日常操作与开发请看[详细操作指南](操作指南.md)；团队介绍请直接用浏览器打开[项目汇报 HTML](项目汇报.html)，支持阅读／汇报模式、交互架构说明和打印。
