复现需本机Java/Maven、OpenCode、已配置模型与可用网络；此命令会产生真实模型费用：

```bash
WORKBENCH_E2E_LIVE=1 WORKBENCH_OFFLINE=1 node --import tsx verification/workbench-e2e-live.ts
```

`WORKBENCH_OFFLINE=1`用于本地构建依赖方式，不表示模型离线；模型仍真实请求已授权DeepSeek地址。脚本最多新建两个本批工作目录，超过后停止，要求核验归属与保留情况，不自动删除历史数据。恢复参数只用于同源码起点和原证据链，不能冒用不同版本结果。
