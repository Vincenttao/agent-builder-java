## 1 当前产品基线

产品主线为“平台开发者提供范式/模板 → 应用开发者配置与少量开发 → 企业 CI/CD 交付”。两类用户使用不同工作区，都可查看与简单修改代码；OpenCode 根据范式开发 Skill 辅助编排。

已确定的规则：

- 新应用从 MOA 模板创建；i豆是后续业务需求，不存在 i豆模板或预建应用。
- 应用方定义业务范围、Skill/Agent 分工、接管目标及续办策略。Skill 在所属任务内调用，不新增独立业务待办。
- 首期任务恢复含当前任务共两层：A→B，B 结束后只恢复仍未结束的 A；保留 A/B 时阻断第三层请求。
- 业务范围、System Prompt 与 Skill 指导冲突时，由 OpenCode 统一定位并提出关联修订；沿用差异审阅、同一修订应用及复核流程。
- 流程图显示已保存定义和预演分支；运行 Trace 与只读回放单独展示。预演不计为真实执行证据。

正式定义与验收以 [PRD](Agent开发工作台_PRD_v2.0.md) 为准，页面规则见[交互设计](Agent开发工作台_交互设计_v2.0.md)。上述真实能力仍待实现或验证；现有 Demo 只说明交互。
