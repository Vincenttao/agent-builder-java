# DEV-02 可运行 Demo 开发计划

日期：2026-10-25。状态：已获用户授权启动，开发分支 `dev/workbench-v2`。目标按[架构 RD-01～06](Agent开发工作台_技术架构设计_v2.0.md#132-首个可运行-demo-到此结束)交付双角色可运行 Demo，完整 PRD 验收仍单独保留。

## 1 交付范围与边界

平台修改/发行一个 MOA 模板，应用方从空模板创建 i豆福利应用，经真实 OpenCode 修改与审阅后，用本机 Java、DeepSeek Flash 和独立 HTTP/A2A Mock 运行。支持带确认兑换、同进程 A/B 续办、真实 Trace/只读回放，以及 JAR/源码独立运行。前端沿用现有 PC 交互；Git/worktree 管内容，SQLite 管索引，Jaeger 管 Trace。不恢复旧 v1 项目。

默认采用可信单人本机开发、同一工程串行操作、一个活动 Java 调试应用。真实企业授权、MCP/通用 Python、跨重启自动恢复、智能构建复用和企业 CI/CD 接入后置。不得以 Mock、页面提示或单次模型 API 代替真实集成证据。
