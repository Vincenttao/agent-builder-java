# 双范式工作台端到端测试用例

本批目标：检查应用/平台两角色、MOA/DeepAgent两范式、PC视觉与交互，以及真实OpenCode能否从空业务开发出可审阅、可运行的应用。历史记录不直接计作本批通过；确定性契约、页面走查、真实模型、Java运行及技术导出分别记录。

所有输入使用虚构业务；模型仅使用已授权的api.deepseek.com。本批使用独立工作目录和本机临时服务，不修改主Demo工程或已有运行。真实生成不得替换成预制方案。一次观察超时不重新启动原任务；失败尝试、修订与重试分别留证。测试输入/预期由本文件及独立断言固定，不能用生成代码修改验收目标。

## 退出条件与结果

必须记录每条用例的实际状态、来源修订、生成任务/运行ID、截图或报告。发现缺陷先定位到产品、实现、测试或模型行为；必要修复后只复测受影响项。未执行或失败用例不计为通过。正式企业接入、生产发布、跨重启恢复和DeepAgent OTel不属于本批已验证承诺。

本批执行结果：E2E-01～16已通过（含修复和一次真实Coding格式补改），E2E-17～18使用本批组件/契约证据，未计作完整模型E2E。详情见[端到端测试报告](端到端测试报告_双范式与Coding助手.md)。
