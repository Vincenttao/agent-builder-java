## 失败与纠正

1. 初始单测夹具的 TypeScript 换行断言语法有误，先纠正测试语法，再确认缺少模块的红灯；没有修改业务验收预期。
2. 首次 UI 检查停在只读字段的标签定位，未发起业务模型请求。为需求字段补明确的可访问标签。
3. 初选历史生成候选 `e622e061…` 可以真实查询，但输出自然语言，不满足现有结构化报告和追问格式。验收 `a1566c84…` 的 TC-001/002 失败，TC-003 通过，完整失败记录保留在 `attempt-2-incompatible-candidate.json`。未更改报告或放宽断言，改用已有兼容模板。
4. 最终浏览器闭环在发布后停留于“业务请求”标签定位；补上该输入框的明确标签后，同一测试、同一报告和发布版本继续完成，没有重新验收或发布。恢复检查再次验证该输入框可操作。
