# TDD-012：固定候选、独立测试入口与预览

日期：2026-10-22。已迁移并部署本地 app；完整 PRD／TD-15 尚未验收。

## 实现范围

本批接入已有模板装配版本的候选登记。候选固定 AgentSnapshot、运行规格摘要和 Runner 实际制品摘要，保存明确来源 `assembled-template`。重复登记同一组合返回同一候选；新制品产生新候选，旧记录不可更新或删除。这是自动开发流程的候选基础，还没有执行 OpenCode 生成代码、构建生成工程或应用候选修改草稿。

TestDeployment 固定候选、确认的需求基线、测试集摘要、模型与 Mock 摘要、环境配置和有效期。平台生成独立 JVM 与 Mock 环境编号；自动测试和人工预览分别创建部署。首批环境为默认种子与正常故障配置，后续候选验收调度还需扩展到完整故障集合。

`/test-api` 与 `/agent-api` 共用 InvocationService、Run、动作审批、去重和取消逻辑。测试解析固定部署，`agentVersion` 为 null，响应携带 candidateId、testDeploymentId 和实际核对的 artifactDigest；测试路径不读取发布指针。会话、请求、身份和环境不得跨部署复用。准入再次在事务内检查测试部署与原请求，避免停止期间的迟到准入。

测试授权由管理会话签发，绑定部署和身份，最长 15 分钟且不超过部署有效期。测试凭据与演示凭据分开，存储中仅保留哈希；正文不能覆盖候选、身份或环境。停止或过期后业务入口拒绝访问，管理接口仍能读取原请求与证据。平台重启后需重新签发授权，不重放历史请求。

部署停止先阻止新请求、取消未准入请求并请求停止活动 Run。确认活动 Run 结束后，Runner 退役 JVM、Mock 释放预留，才记录已停止。退役与释放均可先于迟到启动登记。候选启动失败保留失败原因，完成清理后记录 failed；未知停止结果继续保持 stopping。部署上限 4 个，有效期最长 1 小时。

工作台在每个测试版本中提供候选登记、独立预览、部署记录和停止。候选预览复用模拟 App，显示“未发布候选”、有效期和绑定信息。页面恢复使用原请求编号，授权不写入 URL 或浏览器持久存储。

## 验证

红灯记录包括：候选登记未实现、测试部署未实现、测试授权接口返回 404，以及浏览器缺少候选面板。首次数据库迁移曾错误引用 PostgreSQL 截断后的约束名，现改为查询实际约束再删除；此记录归类为测试准备失败，不计行为红灯。

| PostgreSQL 集成 | 76／76 通过 |

集成测试覆盖候选不可变、重复键、测试集不匹配、身份与会话隔离、装载摘要异常、停止与启动竞争、停止与准入竞争、过期后取消以及历史读取。原生测试先在无发布版本时实际运行候选 v2，再发布 v1，核对两入口结果、JVM、环境和外部调用证据。停止候选后，已发布 JVM 继续就绪。原生测试中的模型响应和完整发布验收准入使用明确替身，不是交付成功率证据。

首次浏览器回归中，发布版测试的跨身份读取断言得到 200；该用例通过未等待完成的异步 response 监听更新凭据。已改为显式等待登录响应并断言返回的 actorId，再执行跨身份读取。最终 U1001 凭据读取 U1002 请求返回 404，两条浏览器流程均通过。保留首次失败，未改动服务端权限逻辑来使断言通过。

本轮仅重建和更新 app，Runner、Mock 与 PostgreSQL 沿用上一轮固定镜像，四服务健康。Java 和 Runner 运行代码未改变；没有声称重跑 JUnit 或验证强隔离。

## 管理与业务入口

| 方法与路径 | 用途 |
| --- | --- |
| POST /api/candidates | 按 snapshotId 登记固定模板装配候选 |
| GET /api/drafts/{id}/candidates | 列出候选 |
| POST /api/test-deployments | 按候选、需求基线、测试集摘要和请求键创建独立部署 |
| GET /api/test-deployments/{id} | 查询实际准备／停止状态与固定绑定 |
| POST /api/test-deployments/{id}/sessions | 管理会话为 U1001／U1002 签发部署授权 |
| POST /api/test-deployments/{id}/stop | 受理停止，等待实际执行结束与 JVM 退役 |
| GET /api/test-deployments/{id}/requests/{requestId} | 管理会话读取历史请求，部署停止后仍可用 |
| POST /test-api/deployments/{id}/messages | 使用测试授权发送消息 |
| GET /test-api/deployments/{id}/requests/{requestId} | 测试授权读取自己的当前请求 |
| POST /test-api/deployments/{id}/requests/{requestId}/actions/{actionId}/decision | 复用动作决定契约 |
| POST /test-api/deployments/{id}/requests/{requestId}/cancel | 复用运行取消契约 |

消息仅接受 input、clientRequestId 和可选 conversationId；正文不能选择环境或目标。测试部署创建接口严格校验已确认的套件摘要，不能降低基线。创建和调用不会生成“候选验收通过”报告。
