# TDD-060：模拟执行不得发布纳入验收门禁

日期：2026-10-22。状态：AC-20 单分支通过；P0-A 与 TD-15 尚未完成。

## 问题

AC-20 要求验证“仅有模拟执行测试通过时尝试发布，平台必须阻止发布”。验收 manifest 将所有用例固定标成 `live-mock`，无法准确表达 AC-20 的模拟执行输入，且该项没有挂接现有发布门禁测试。

## 实现与测试

- AcceptanceCase 的预期执行模式允许 `simulated`，并将 AC-20 的预期模式设为 `simulated`。
- AC-20 关联 `ProjectReleaseGate` 测试。测试确认模拟模型报告会因 `REAL_EXECUTION_REQUIRED` 被拒绝，未验证报告会因 `VALIDATION_NOT_PASSED` 被拒绝。
- 保存 Vitest 输出并由证据装配器校验测试名称和成功计数，再按 SHA-256 纳入受管验收报告。该分支证明门禁逻辑，不宣称完成真实模型运行。
- 修正 P0-A 报告装配边界：P0-B 的 AC-29a/NF-06 分支不能作为未知结果混入 P0-A 报告。
