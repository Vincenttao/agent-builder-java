# TDD-066：受限生成策略拒绝记录与幂等读取

日期：2026-10-23。状态：实现、单测／契约／集成测试、Docker 构建及新镜像 API 冒烟通过；AC-23 仍未全项关闭。

## 问题

`DevelopmentService.start()` 原先在创建开发任务前直接抛出策略错误。超范围 scope、依赖、连接和 profile 请求虽然被拒绝，但没有持久任务、诊断事件或可查询历史，与 PRD FR-018／AC-23 的“拒绝并留记录”不符。

## 红—绿实现

- 先增加 PostgreSQL 集成测试，提交四种不受支持的生成配置，并要求每个请求都留下失败记录、具体诊断码、`policy.rejected` 事件；相同请求重试返回同一任务，Runner 不得收到提交。初次运行因 `start()` 直接抛 422 而失败。
- 策略检查移至已确认快照／基线解析之后。拒绝请求现在以终态 `failed` 保存；Tester／Developer 状态为 `skipped`；同一数据库事务写入序号 1 的策略拒绝事件。由于任务已终态，不进入 Runner 调度。现有输入摘要与唯一请求键保持不变。
- 四类拒绝分别验证 `GENERATION_SCOPE_UNSUPPORTED`、`DEPENDENCY_NOT_ALLOWED`、`BUSINESS_CONNECTION_NOT_ALLOWED`、`GENERATION_PROFILE_UNSUPPORTED`。再次提交同一 clientRequestId 返回原任务，不会产生重复记录或 Runner 任务。
