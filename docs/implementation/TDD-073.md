# TDD-073：生成金融余额 Tool／Skill 并完成候选验收

日期：2026-10-23。状态：金融只读生成与候选验收在 NF-01 Docker 栈通过；TD-15 全量回归仍未完成。

## 目标

在真实部署的 App／Runner 上，通过双角色开发任务生成 Java 余额 Tool 和查询 Skill，冻结为候选，再由独立验收执行器运行企业 Mock 的正常、缺少账户号和接口超时场景。验收同时检查返回值、Skill／Tool 运行证据和 Mock 外部状态。

## TDD 与修复

此前现场回归中，余额正常和缺少账户号场景已通过，超时场景因输出没有 `message` 字段而失败。验收规则要求失败输出使用结构化 JSON，并明确余额未知；默认余额装配模板已包含此要求，但本次现场脚本自定义的系统提示遗漏了该字段。

修订现场提示，使其与模板及验收规则一致；增加断言回归，证明含超时码和说明的输出通过，缺少说明时失败。归档原失败记录为 `finance-generation-prompt-mismatch.json`，保留失败与修复轨迹。
