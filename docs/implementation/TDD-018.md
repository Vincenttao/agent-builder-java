日期：2026-10-22。状态：本批页面已部署；完整 PRD／TD-15 仍未完成。

## 交付行为

- 组件目录按 Skill、Rail、Tool 筛选，展示能力说明、标识、依赖和当前选择状态；创建草稿前也可浏览。
- 两个内置 Tool：设备查询、维修工单；三个内置 Rail：执行审计、工具白名单、写入确认。
- 设备查询 Skill 标记为“需自动开发”。模板本身没有 Skill；生成构建通过原候选登记流程绑定 Tool 和 Skill，页面分别显示待登记组合及已登记候选的真实绑定状态。
- 勾选工单 Tool 时自动加入写入确认 Rail，取消时移除；设备查询、审计、工具白名单保留。默认指令随组合切换，手动指令不被覆盖。
- 装配预览显示 DeepAgent、Tool、Rail、Skill 状态，固定按钮沿用现有快照 API；能力组合同步选择只读或工单验收基线。
- 桌面双列卡片，窄屏单列；沿用原工作台风格。操作方法已更新至操作指南。
