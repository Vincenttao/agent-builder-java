## 运行与恢复约束

- 调试固定快照及 Java 制品摘要；去重范围是快照与 clientRequestId，同键不同输入冲突。Run 的环境、身份与输入固定，JSON 字段删除也必须拒绝。
- Runner 先持久化执行请求再调用 JVM；相同请求可查询或重试取得原结果。Runner 重启后的未完成执行标记 interrupted，不自动重放。
- 平台通过执行编号恢复已受理请求。外部证据获取失败不当作零调用；依赖失败有次数上限，耗尽后标为 interrupted。
- 取消受理显示 cancelling；收到 Runner 停止确认并采集证据后才进入 cancelled。每个设备调试 Run 使用独立 JVM 与 Mock 实例，终态后停止对应 JVM。
- API 支持持久化事件分页及 SSE 续读；当前工作台通过轮询展示状态与事件。尚未验证长时间事件保留、全部多轮续接和宿主 Runner 非正常退出后的孤儿进程处置。
