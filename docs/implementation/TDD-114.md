# TDD-114：接通独立金融 Tool／Skill 生成并完成本地真实验收

日期：2026-10-24。状态：`wealth-balance-tool-java@1` 与 `wealth-balance-skill-java@1` 已接通本地平台，真实双角色生成、候选构建和 Mock 金融验收通过。TD-15 尚未完成；本轮未推送 GitHub，也不以远端 CI 结果作为本地交付判据。

## 实现

- 增加 Tool-only 和 Skill-only 余额生成 Profile。Tool-only 仅允许 Developer 写余额 Tool 与 Java 单测，平台固定物化已审阅 Skill；Skill-only 仅允许写余额 Skill，平台物化固定 Tool 与单测。两个范围都不能借生成请求扩展写入权限。
- Skill-only 通过余额 Skill 合同执行先红／后绿检查，并在构建时冻结绿灯 Skill 摘要；绿灯后修改会被拒绝。
- 生成制品登记为 `generated-tool-skill@3`，记录严格的单一 `generatedScope`。Java Bridge、候选服务、运行事件和验收证据按 scope 区分生成 Tool 调用与固定 Tool 调用。
- 装配页面加入“单独生成余额 Tool”和“单独生成余额 Skill（使用固定 Tool）”入口，并按所选范围绑定对应 Profile。
- 扩展 `verify-td15-finance-generation-live.mjs`，支持 Tool-only、Skill-only 和原有组合范围；验证器把执行器合成的先红／后绿事件与有独立命令记录的执行步骤分别取证，并核对运行清单的生成范围。
