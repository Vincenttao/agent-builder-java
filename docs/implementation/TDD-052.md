# TDD-052：冲突 Rail 与不支持 Agent 类型验收

## 目标

验证装配入口会拒绝重复 Rail 与不支持的 Agent 类型，并在拒绝后保留原草稿、不创建部分快照。

## 实施

- 新增 `scripts/verify-td15-ac06-incompatible-assembly.mjs`，对当前隔离 Docker App 执行真实快照创建请求。
- 使用重复 `audit@1` 验证冲突 Rail；使用 `ReAct` 验证不支持类型；检查错误原因及数据不变性。
