# TDD-006：工单审批、原生续接与写入核对

日期：2026-10-22。状态：平台完整服务链路的批准、拒绝、过期与写后超时测试通过；Docker 中的真实 DeepSeek 页面审批和终态数据重启检查通过。不是 TD-15 或 P0-A 完成结论。

## 已实现行为

平台把真实 SDK 的待执行工具调用转换为持久化动作，绑定 Run、模拟用户、环境、快照摘要、制品摘要、工具调用编号、规范化参数及有效期。批准决定持久化后，Runner 以固定决定编号续接原 JVM 会话；设备查询和原始任务不重放。工具代理再次检查平台授权，模型参数不能覆盖身份、批准状态、幂等键或目标地址。

确认有效期为 5 分钟，过期由运行工作线程检查。拒绝或过期请求取消对应调试 JVM；平台收到停止确认后显示 cancelled，保留已输出的设备分析、查询记录和审批事件。审计只保存有界的公开答复内容，不保存模型推理字段或原始提示；已配置的模型与控制令牌在写入事件前替换。

平台使用动作编号作为业务幂等键，数据库事务只允许首次认领写入。重复决定返回原决定，改变投票冲突；不同服务实例不能同时认领同一写入。返回不明时记录 unknown，按原键查询；查到结果后保存外部结果，未查到时保留待核对状态，不再次发出写入。

## 保留边界

- 当前工作台为单用户模式，调试身份固定为模拟用户 U1001，不代表企业身份接入或多租户隔离。
- 原生续接依赖原 JVM 中的 SDK 会话。刷新浏览器不丢失平台动作；Runner／JVM 重启后的等待会话不能据此恢复，也不会重放原任务。
- 当前通过的完整链路每次只有一个待确认工具；批量中断、多个并行待确认写操作和共享 JVM 会话取消尚未验证。
- 本切片覆盖设备模拟工单；金融写操作、完整未知结果恢复、候选服务入口与双角色自动生成仍需后续切片。
