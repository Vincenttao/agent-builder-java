# TDD-050：需求问答与表单双向切换验收

## 目标

验证问答输入与表单输入共用同一份需求状态。双向切换需保留字段值；只编辑的字段清除旧确认状态；保存并刷新后字段值和确认状态按预期恢复。

## 实施

- 新增 `tests/e2e/requirements-mode.spec.ts`，在固定隔离 Docker App/Runner 上通过真实浏览器登录、输入、切换、确认、保存和刷新。
- 记录双向切换、字段确认状态与刷新恢复断言，并将证据绑定当前 App／Runner 镜像摘要。
- 将 AC-02 的 `guided-to-form` 和 `form-to-guided` 两分支接入受管证据装配器及 P0-A 固定目标门禁。

## 验证结果
