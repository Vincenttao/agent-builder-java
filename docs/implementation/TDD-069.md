# TDD-069：登记金融余额生成规格并隔离未实现 Profile

日期：2026-10-23。状态：受限准入检查通过；金融生成能力本身尚未实现。

## 问题

企业 Mock 已提供余额等金融接口，但现有自动开发执行器只实现设备 Tool／Skill Profile。只在共享策略层登记新的 Profile 会让请求落入设备生成模板，形成错误的候选，因此平台和 Runner 必须区分“规格已审阅”与“执行实现已就绪”。

## TDD 结果

先在 Runner Profile 测试中加入 `wealth-balance-java@1`，固定其允许范围为 `tool + skill`、依赖为已固定 OpenJiuwen／Agent Builder Bridge、连接为 `mock-finance@1`。测试先因金融 Profile 未登记而失败，再实现版本化 Profile 校验。

随后加入实现就绪门禁：当前仅 `equipment-java@3` 可执行；余额 Profile 的策略字段正确时返回 `GENERATION_PROFILE_NOT_IMPLEMENTED`。Server 开发任务入队前和 Runner 任务执行前共用该门禁，防止 Server/Runner 对能力范围理解不一致。生产业务连接、额外 Scope、未审阅依赖和 Profile 版本漂移继续拒绝。
