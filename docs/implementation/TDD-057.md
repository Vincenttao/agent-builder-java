# TDD-057：写入目标需求影响提示

日期：2026-10-22。状态：实现完成；AC-03 三个分支在隔离 Docker 浏览器验收通过。P0-A 全量报告尚未基于本次 App 镜像刷新。

## 目标

按 PRD FR-002/003 实现 AC-03：用户将只读目标改为创建工单时，提示写操作确认要求与缺失接口资源，同时保留目标使用者、交付内容等无关需求字段。

## 实施

- 新增 `requirementImpact` 确定性检查，只对明确的创建、提交或写入意图给出影响提示；只读目标不触发。
- 表单与引导填写共用同一需求状态，均显示审批要求、工单写入接口缺口和“不会覆盖其他字段／不会假定接口存在”的说明。
- 提示不自动修改已确认字段，也不将资源缺口伪装为已绑定能力；代码生成仍须基于用户提供的接口契约。
- 新增纯函数单测和 AC-03 Playwright 场景。先执行单测确认模块缺失时失败，再实现后通过。
