# TDD-036：开发任务时限触发与停止确认

日期：2026-10-22。状态：当前部署上的 20 秒任务预算超限测试通过；NF-04 轮次上限和完整错误分类仍待验证。

## 方法与结果

- 新增 `scripts/verify-td15-nf04-budget.mjs`。脚本在已构建设备查询项目的固定快照／基线上启动一项新的真实开发任务，使用当前受限 GenerationProfile 和 20 秒任务预算，不改动已发布候选。
- 任务在测试 Agent 阶段达到预算上限，服务返回终态 `failed` 和诊断 `ENGINEERING_BUDGET_EXCEEDED`；测试角色状态为 `cancelled`，开发角色为 `skipped`。这表明任务已进入角色执行阶段，预算终态可识别，执行器确认停止后才结束，不是仅验证请求参数校验。
- 任务 ID、快照 ID、角色终态、预算与 verdict 见 [NF-04 时限证据](evidence/TD15-NF04-budget-live.json)。失败尝试按平台规则保留，没有被覆盖为成功任务。

## 范围限制

本次只验证受限开发任务的总时限，不验证业务 Agent 的 `maxIterations` 边界，也未覆盖所有阶段错误归类和运行中强杀失败的对账路径。20 秒时限是在开发任务 API 上配置，不能推导为业务 Run 超时。NF-04 及 P0-A 仍未完整通过。
