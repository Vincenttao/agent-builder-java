## 启动与版本

见[仓库启动说明](../../README.md)。Compose 项目名为 `agent-builder-platform`，与本机已有其他项目区分。app 仅监听宿主 `127.0.0.1:8080`，数据库不发布宿主端口；专用测试数据库另用 15432。

镜像固定 Node 与 PostgreSQL 基础镜像摘要，JavaScript 依赖由锁文件固定。实际 Node、数据库、OpenCode 及应用镜像标识记录在证据摘要中。原型主机使用 Node 22.20.0 开发，正式容器已按 Node 24 验证。

生产依赖打包使用 pnpm 从共享锁文件生成专用部署锁文件，并离线组装；不在部署步骤重新解析版本范围。构建阶段的开发依赖不进入最终 app 镜像。

DeepSeek 密钥保存在 Git 忽略的 `.env.local`，OpenCode 配置仅引用环境变量；诊断报告不保存密钥、完整模型提示词或内部推理。工作台 UI 没有获取 DeepSeek 密钥的接口。
