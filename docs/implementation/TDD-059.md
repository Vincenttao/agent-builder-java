# TDD-059：真实 OpenCode 子进程取消与平台角色终态一致

日期：2026-10-22。状态：AC-29a 的运行子进程取消分支通过；完整 AC-29a、NF-06 和 TD-15 尚未完成。

## 目标

使用隔离 Docker 目标证明开发任务取消会停止实际托管的 OpenCode 进程，并让平台任务记录反映 Runner 的终态角色状态。

## TDD 与实现

- 先增加 Runner 单元测试和 Postgres 集成测试，验证取消后排队角色转为 `skipped`，以及平台保存 Runner 的终态角色；初次运行按预期失败。
- Runner 取消尚未启动的任务时，将所有排队角色标记为 `skipped`。
- 平台收到 Runner `cancelled` 后读取并合并终态任务记录。若 Runner 明确返回 `ENGINEERING_NOT_FOUND`，表示任务在首次提交前已被取消，平台将仍排队的角色标记为 `skipped` 并终结任务；其他查询错误仍保持可重试的取消中状态。
- 保留“不同基线拒绝、取消与迟到提交竞态”及修复次数预算测试，并将其假 Runner 适配为返回与 HTTP Runner 一致的明确 Not Found 错误。
