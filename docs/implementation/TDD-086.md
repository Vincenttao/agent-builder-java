# TDD-086：金融余额 Tool 与 Skill 双 Agent 生成闭环

日期：2026-10-24。范围：本地固定 TD-15 镜像上的 AC-31 真实生成与验收；未重建 Docker 镜像，也不依赖 GitHub CI。

## 实现与验证

- 使用 `wealth-balance-java@1` 从空业务组件选择生成余额查询 Tool 与 `balance-query` Skill；请求夹具由验证脚本定义，未作为服务端 HTTP 抓包。
- Tester 与 Developer 两个角色均完成。生成候选通过测试先红后绿：桩实现的单测失败，补齐实现后单测通过；契约检查和 JAR 构建通过。模型首次输出的错误测试和桩测试红结果也保留在任务命令记录中。
- 固定候选在真实 Mock 运行中完成三条余额验收：正确查询返回外部账户事实；缺账户号时追问且业务调用为 0；读取超时返回 `TOOL_TIMEOUT` 且不将余额当作已知。
- 执行轨迹包含 `skill_loaded`、`generated_tool_invoked`、Tool 调用和超时事件；候选及生成文件摘要记录在证据中。
- 首次在线生成尝试以 `ENGINEERING_EXECUTION_FAILED` 结束，Developer 角色仍为 running；保留该失败记录。之后在隔离端口执行的第二次尝试成功，完整记录为本次验收依据。

## 边界

本记录证明 AC-31 的只读余额 Tool/Skill 生成和测试闭环。空 Rail 定义是该生成 Profile 的当前限制；未验证 Rail 生成，也未覆盖理财产品查询、申购、手机 App 发布入口或完整 AC-32/TC-001 等场景。不得将本项结果描述为完整金融 Agent 发布通过。

请求夹具元数据明确标注为从验证脚本还原，不是原始 HTTP 报文。服务运行事件、候选、构建命令和验证证据来自 live-mock 运行记录。
