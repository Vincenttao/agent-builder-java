# TDD-021：参数化工具调用上限 Rail 首个切片

日期：2026-10-22

## 范围

依据 PRD FR-006、FR-018 和 AC-22d，完成一个受审阅 Rail 模板的实际 SDK 装配与触发：`tool-call-limit@1:N`，其中 N 为每次 Agent Run 允许的工具调用数，范围 1–20。该增量提供 Rail 配置与执行基础，不代表开发 Agent 已能从自然语言自动生成 Rail 定义或 Java hook。

PRD 与实施计划补充了 G1–G4 生成增量和 TD-12A–D 红—绿门禁。当前双角色自动开发仍仅生成设备只读 Tool／Skill；自然语言生成 Rail 配置、生成产物锁定、独立验收及 Agent 工程生成仍未完成。

## TDD 记录

1. 新增真实 DeepAgent 循环测试，配置 `tool-call-limit@1:1`，模型连续请求两次工具调用，要求第二次调用前触发 Rail 事件且外部 Tool 实际调用只有一次。
2. 红：未实现时装配拒绝 `UNKNOWN_RAIL:tool-call-limit@1:1`。
3. 绿：加入受限参数解析和固定 SDK Rail。Rail 在每次 `beforeInvoke` 重置 Run 计数，在 `beforeToolCall` 以 Session 状态计数；达到上限后调用 SDK `requestForceFinish`，不执行后续 Tool。
4. 增加每次 Run 重置、范围边界和未知模板版本拒绝的回归断言。
5. 增加页面装配选择、服务端配置校验与 RuntimeSpec Schema 支持；参数只接受 1–20 的登记模板格式。
