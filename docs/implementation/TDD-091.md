# TDD-091：单一理财 Agent 查询余额与产品目录

## 目标

推进 AC-32：模拟企业 App 使用同一个已发布 Agent 查询账户余额和理财产品目录。该场景覆盖受限生成的 Tool、统一 Skill、候选制品绑定、Java Runtime Bridge 调用、业务 Mock 请求和已发布版本证据。

## 实施

- 新增 `wealth-assistant-java@1` 受限生成 Profile；将 `get_account_balance` 与 `list_wealth_products` 两个只读操作绑定到一个 `WealthQueryTool` 类和 `wealth-query` Skill。
- 增加 `generated-tool-skill@2` 制品清单。运行时校验每项 Tool 与 Operation 的绑定、类摘要和 Skill 摘要；Agent 装配要求实际工具集合与制品绑定集合完全相同。
- 在 Java HTTP Tool 契约中支持数组响应字段，使产品目录 `items` 能通过契约验证。
- 注册只接受空参数的 `listWealthProducts` 只读代理路由，并通过固定运行上下文核验 Operation 授权。
- 在装配页面增加“理财余额与产品查询”模板；仍以余额必测基线验证生成候选，发布后的 AC-32 脚本再从模拟 App 分别执行余额和产品查询，并校验两次请求使用相同发布版本和候选摘要。
- 将 AC-32 manifest 入口指向 `scripts/verify-td15-ac32-wealth-assistant-live.mjs`。

- 单元与契约测试通过：36 个测试文件、135 项测试。

- 受限生成适配器测试通过：2 项，包括有效红、实现后绿、契约构建及 `@2` 制品组合。
- Web 装配页 Playwright 夹具测试通过 1 项；生产 Web 与 TypeScript 构建通过。
