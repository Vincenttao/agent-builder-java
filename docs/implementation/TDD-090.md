# TDD-090：修复 Windows Corepack 环境下的生产构建入口

日期：2026-10-24。范围：让仓库根目录的 `build` 命令在仅安装 Corepack、未单独安装 pnpm shim 的 Windows 环境中可运行。

## TDD 与结果

- 先运行 `corepack pnpm build`，Web 构建尚未启动，cmd 返回 `'pnpm' is not recognized`。直接调用 `corepack pnpm --filter @agent-builder/web build` 与 `corepack pnpm exec tsc -p tsconfig.build.json` 均通过，定位到根 `package.json` 脚本内部使用裸 `pnpm`。
- 将根构建脚本改为 `corepack pnpm --filter @agent-builder/web build && tsc -p tsconfig.build.json`。
- 再次运行原始入口 `corepack pnpm build`：Vite 生产构建和 TypeScript 发布构建均通过。

本项是本机生产构建入口验证，不替代 Docker 镜像构建或 TD-15 现场验收。
