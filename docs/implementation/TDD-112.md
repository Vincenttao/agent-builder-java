## 设计与实现

AC-22a/b 需要分别提交 Tool 与 Skill 生成任务。为落实最小写权限，登记两种固定金融 Profile：

- `wealth-balance-tool-java@1`：scope 仅为 `tool`，Developer 可写余额 Tool Java 源码与对应单测。
- `wealth-balance-skill-java@1`：scope 仅为 `skill`，Developer 只能写 `skills/balance-query/SKILL.md`。

两者固定使用已审阅依赖 `openjiuwen-core@0.1.17`、`agent-builder-bridge@0.1.0` 和 `mock-finance@1`。Profile 将完整组件路径与 Developer 可写路径分开；测试角色仍可只读查看实现副本。服务端／Runner 的 `generationImplementationError` 仍返回 `GENERATION_PROFILE_NOT_IMPLEMENTED`，因此请求不会进入错误的组合式构建流程。
