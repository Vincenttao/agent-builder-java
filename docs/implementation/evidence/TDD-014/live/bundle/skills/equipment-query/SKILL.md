# 设备查询（equipment-query）

## 用途

当用户询问某台设备当前的状态、温度或数据来源时，使用本技能。
事实只能来自已绑定的只读工具 `get_equipment`，不得依赖猜测、历史记忆或示例数据。

## 输入

- `equipmentId`：字符串，必填，设备编号（例如 `PUMP-001`）。
- 不要接受或传递 `actorId`、`endpoint`、URL、令牌等身份或连接参数；这些由平台运行时通过受信任的 kwargs 注入。

## 调用步骤

1. 从用户消息中提取设备编号。
2. 若缺少 `equipmentId`，先向用户追问设备编号，不要调用任何工具。
3. 仅以 `{"equipmentId": "<设备编号>"}` 调用工具 `get_equipment`，不要附加其他输入字段。
4. 读取工具返回的四个字段并如实转述：
   - `equipmentId`：被查询的设备编号。
   - `status`：设备状态（如 `ok`、`warning`）。
   - `temperatureCelsius`：摄氏温度数值，可能为 0 或负数，保持原值。
   - `source`：数据来源标识。
5. 只转述工具返回的内容；返回中不存在的字段（例如位置、负责人、维护建议）不得补充或推测。

## 错误处理

- 输入错误 `TOOL_INPUT_CONTRACT_INVALID`：说明设备编号缺失或格式无效，追问或请用户澄清，不调用工具、不编造结果。
- 响应错误 `TOOL_RESPONSE_CONTRACT_INVALID`：说明设备数据不可用/格式异常，明确告知查询失败，不提供任何状态、温度或来源。
- 工具超时或其他传输异常：明确告知查询失败及可稍后重试，不重试写操作、不编造状态或来源。
- 任何失败场景都不得输出示例值、默认值或推测值。

## 约束

- 本技能是业务指令加 Tool 适配层，不执行外部脚本。
- 工具为只读查询，不执行设备写操作。
