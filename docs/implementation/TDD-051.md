# TDD-051：无效 Tool 与 Rail 装配拒绝验收

## 目标

在当前固定 App／Runner 镜像上验证：未知 Tool 和超出合法取值的 Rail 参数不能固定成可运行快照；失败请求不能改变草稿，也不能留下部分快照。

## 实施

- 新增 `scripts/verify-td15-ac04-invalid-assembly.mjs`，通过隔离 Docker App 的真实 HTTP API 创建需求、提交两种非法装配并核对错误及持久化状态。
- 将 AC-04 的 `unknown-tool`、`invalid-rail-parameter`、`invalid-change-not-applied` 三分支接入固定目标受管证据。

## 验证结果

两类非法快照请求均返回 HTTP 422 `INVALID_ASSEMBLY`：未知 Tool 的原因是 `UNKNOWN_TOOL:unknown-business-tool@1`；`tool-call-limit@1:0` 被拒绝，原因是 `UNKNOWN_RAIL:tool-call-limit@1:0`。需求草稿与创建前完全相同，快照列表仍为空。

当前实现没有单独的 `INVALID_RAIL_PARAMETER` 原因码；本次验收证明非法值被拒绝，不证明错误分类已细化。证据见 `evidence/TD15-AC04-invalid-assembly.json`。

P0-A 报告 `P0-A-1792667756287.json`：18/70 分支通过、52/70 未验证、0 失败。AC-04 通过不代表 P0-A 或 TD-15 整体验收通过。
